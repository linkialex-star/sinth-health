# Sinth Health

Base inicial de desenvolvimento do ecossistema **Sinth Health**.

A primeira frente prevista é a **Sinth Psi**. O projeto começa com Vite, React e TypeScript para permitir conexão com o Lovable e evolução incremental do código.

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Estrutura

- `src/`: aplicação React e estilos
- `docs/PROJECT.md`: visão, princípios e etapas iniciais
- `.env.example`: nomes de variáveis esperadas (sem credenciais)

## Integração com Lovable

Conecte este repositório pelo fluxo de integração GitHub do Lovable. Selecione `linkialex-star/sinth-health` e mantenha a sincronização habilitada.

## Segurança e privacidade

Não adicione dados reais de pacientes, prontuários, tokens ou credenciais ao repositório. Configure segredos apenas nas variáveis de ambiente da plataforma. O projeto é um esqueleto técnico e não está pronto para uso clínico ou produção.

Consulte [docs/PROJECT.md](docs/PROJECT.md) para o plano inicial.
