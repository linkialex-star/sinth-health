# Sinth Health — visão inicial

## Objetivo
Construir a base tecnológica do ecossistema Sinth Health. A primeira frente funcional prevista é a Sinth Psi.

## Princípios
- Arquitetura modular: separar o núcleo da plataforma dos módulos de produto.
- Privacidade desde a concepção: minimizar dados pessoais e restringir acessos.
- Segurança: não versionar credenciais, tokens, chaves privadas ou dados reais de pacientes.
- Acessibilidade, responsividade e clareza de interface.
- Mudanças pequenas, documentadas e revisáveis.

## Primeira etapa
1. Validar a conexão GitHub ↔ Lovable.
2. Definir escopo e fluxos da Sinth Psi.
3. Definir autenticação, perfis e permissões.
4. Projetar agendamento e confirmação de pagamento.
5. Planejar integrações externas (por exemplo, calendário e pagamentos).
6. Revisar requisitos de LGPD e normas profissionais antes de usar dados reais.

## Stack inicial
Vite + React + TypeScript. A camada de backend e banco de dados ainda será definida.

## Estado
Esqueleto inicial de desenvolvimento. Não é um sistema clínico pronto para produção.
